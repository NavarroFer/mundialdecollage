# Propuesta de patrocinio del Mundial de Collage

Material comercial para marcas en Argentina. Versión del 7 de octubre de 2026.

- `propuesta-patrocinio-mundial-de-collage.pdf`: documento para presentar a marcas.
- `generar_propuesta.py`: fuente editable del PDF (textos, métricas, precios y diseño).
- `fuentes/`: capturas originales que respaldan las métricas incluidas.

## Modificar y generar

Desde la raíz del repositorio, con Python 3 y ReportLab instalado:

```sh
python3 docs/patrocinio/generar_propuesta.py
```

El generador usa el logo y la tipografía existentes en `public/logo-mark.png` y
`assets/Anton-Regular.ttf`. Escribe el PDF en esta misma carpeta. Revisar visualmente
el PDF después de modificarlo.
